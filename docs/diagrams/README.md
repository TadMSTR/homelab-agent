# docs/diagrams

Architecture diagrams for the homelab-agent platform. Source format is draw.io (`.drawio.svg`) — editable in [draw.io](https://app.diagrams.net/) and renderable directly in GitHub.

| File | What it shows |
|------|--------------|
| `agent-isolation.drawio.svg` | Unix user isolation model — per-agent file permissions, home directories, and credential scoping |
| `analytics-stack-topology.drawio.svg` | Analytics and observability stack — Langfuse, SigNoz, ClickHouse, MinIO, and their network relationships |

For Mermaid diagrams embedded directly in documentation, see the individual component docs (e.g., `docs/components/memory-architecture.md`, `docs/components/scoped-mcp.md`).
